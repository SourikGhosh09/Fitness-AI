# Fitness AI — Momentum v0.2.0

## Purpose
Momentum is the first visual redesign of the mobile app and the UI companion to Phase 2 adaptive programming.

## Design direction
The redesign takes inspiration from modern dark fitness applications without copying the supplied reference screens. It uses a near-black canvas, layered graphite cards, a vivid blue action system, large typography, persistent bottom navigation, compact metric cards, and clearer information hierarchy.

## Navigation
- Today — readiness and generated workout
- Plan — manual/contribution workflow today; schedule-aware weekly planning is the next Phase 2 milestone
- Exercises — searchable verified exercise library and tutorials
- Progress — XP, history and adaptive workload information
- Coach — bounded training explanations and knowledge tools
- Profile — API, learning, Notion, nutrition and account controls

## Functional preservation
The redesign intentionally preserves authentication, readiness, workout generation, set logging/offline queue, substitutions, exercise tutorials, contribution workflow, progress, coach, learning consent, Notion sync, nutrition, API keys and sign-out behavior.

## Versioning convention
Future packaged releases should receive both a semantic version and a short codename. Example: `v0.2.0 — Momentum`.

# UI Specification — Momentum

## Design direction
Original dark fitness interface inspired by modern training apps without copying a specific product: near-black canvas, graphite cards, restrained electric-blue accent, strong hierarchy, large touch targets and clear adaptive explanations.

## Navigation
Primary information architecture: **Today · Plan · Exercises · Progress · Profile**, with Coach accessible contextually/within the product navigation as implemented.

## Major experiences
**Today:** readiness, recovery/fatigue state, today's session, duration/muscle focus, primary Start action. **Plan:** weekly training/rest schedule and adaptive changes. **Workout:** exercise media, sets, rep range, load, RPE/RIR, rest, target muscles, Why this?, Replace/Edit where safe. **Exercises:** search/filter library and GIF tutorials. **Progress:** strength/body-weight/volume/consistency/recovery/progression trends. **Profile:** goals, equipment, schedule, assessment, consent, integrations, export/security/settings.

All displayed prescription values must come from backend state or be explicitly labeled estimates. Loading, empty, offline, validation and safety-blocked states must be distinguishable. Support scalable text, screen-reader labels and comfortable touch targets.
